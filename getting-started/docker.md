# Docker

The Nails Docker environment is a relatively opinion-free LAMP stack all contained within Docker. It comes pre-loaded with helpers, such as the [Command Line Tool](../command-line-tool.md).

The environment is fully documented over at [docker.nailsapp.co.uk](https://docker.nailsapp.co.uk)

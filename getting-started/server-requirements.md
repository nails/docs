# Server Requirements

Nails has a few basic system requirements which need to be satisfied in order for it to run.

* PHP >= 7.3.0
* [JSON PHP Extension](https://www.php.net/manual/en/book.json.php)
* [PDO PHP Extension](https://www.php.net/manual/en/book.pdo.php)
* [Composer](https://getcomposer.org/)

{% hint style="info" %}
These requirements are all satisfied by the [Nails Docker](http://docker.nailsapp.co.uk) environment.
{% endhint %}

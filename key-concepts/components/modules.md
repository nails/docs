# Modules

Modules are defined in the `application/modules/` directory and have the following structure:

```
application/
    ↳ modules/
        ↳ books/
            ↳ controllers/
                ↳ books.php
                ↳ reviews.php
            ↳ views/
                ↳ index.php
                ↳ reviews.php
```

In the above example we have a module called `books` which contains two controllers, `books` and `reviews`.

# Introduction

Nails is an open-source PHP framework. Super easy to install and work with, it provides numerous handy modules to suit most common use cases – leveraging the [Composer](http://getcomposer.org/) ecosystem in order to bring about additional functionality 😍

![](<.gitbook/assets/Screenshot 2020-03-01 20.33.24.png>)

Out of the box, Nails provides the [bare essentials](core-services/) for building MVC applications - a deliberate decision in order to keep the operating footprint as low as possible.

Nails' real power comes through the use of [components](key-concepts/components/), allowing complete chunks of functionality to be brought in so time and money can be spent on building **The Important Stuff ™️ 🧐**

Nails is a young framework, but one which is actively developed with features, fixes and updates being pushed almost every day – [join us on Slack if you have any questions](https://nails-app.slack.com/) 🙋‍♀️

Nails is not an out-of-the-box, plug-and-play CMS, blogging platform or shopping platform (like WordPress, Drupal or ExpressionEngine); it is a tool for developers, allowing them to build any type of site efficiently and effectively without coercing a tool that doesn't quite fit their needs.

# Google ReCaptcha

This driver provides form protection via [Google's reCAPTCHA](https://www.google.com/recaptcha) service.

## Installation

Install using Composer:

```bash
composer require nails/driver-captcha-recaptcha
```

## Configuration

This driver is configured in [Admin](../../../admin/), under Captcha settings. You will need the `site key` and `site secret` as [provided by Google](https://www.google.com/recaptcha/admin/create).

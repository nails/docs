# UserSnap

This module enables UserSnap across the front and back ends of your application.

You have the following [configuration values](../../getting-started/configuration.md) which can be set:

| Value                      | Description                                                                       |
| -------------------------- | --------------------------------------------------------------------------------- |
| `USERSNAP_KEY`             | Your UserSnap project key, required                                               |
| `USERSNAP_ENV`             | Which environments you'd like UserSnap to be enabled on, can be a string or array |
| `USERSNAP_FRONTEND_ENABLE` | Independently enable/disable UserSnap on the front end                            |
| `USERSNAP_ADMIN_ENABLE`    | Independently enable/disable UserSnap in Admin                                    |
